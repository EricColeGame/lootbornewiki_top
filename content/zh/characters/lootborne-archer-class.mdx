## 为什么 Lootborne 弓箭手职业会奖励有耐心的玩家

在 Lootborne 中，很少有事情比沿着走廊风筝一群精英、并在它们碰到你之前全部击杀更爽。Lootborne 弓箭手职业将站位、时机与装备质量转化为纯粹伤害，这正是它频繁出现在单人刷图路线和协调团队推进中的原因。如果你正在决定先练什么——或者你已经创建了一个，却总在每场战斗的前十秒内阵亡——本指南会解释这个职业实际该如何玩。

选择 Lootborne 弓箭手职业意味着接受一个明确的取舍：在远程时你的伤害几乎超过一切，但当有东西近身时你也会迅速倒下。此后每一个决定——属性、装备、技能、站位——都是为了保护你的距离，同时榨取更高的每秒伤害。

请将本指南的其余部分视为框架，而非死板脚本。Lootborne 是一款以掉落驱动的游戏，因此两个技能完全相同的弓箭手，也会根据实际掉落到的词缀和武器类型而玩得截然不同。

### 弓箭手职业一览

| 特性 | 可期待内容 |
|---|---|
| 主要定位 | 远程单体伤害，可选范围清怪 |
| 伤害模式 | 前置爆发，随后进入更平稳的持续输出阶段 |
| 理想距离 | 远距离——你希望敌人处在屏幕边缘 |
| 生存能力 | 低；距离就是你的护甲 |
| 机动性 | 通常有一次冲刺或翻滚，外加一个减速或定身手段 |
| 最佳内容 | Boss、精英刷取、在前排身后的团队玩法 |
| 最弱内容 | 狭小竞技场中无法避免的近战压力 |
| 装备依赖 | 高——武器品质会显著影响你的伤害 |

## Lootborne 弓箭手职业的优缺点

弓箭手不是“安全”的职业。它是一个将正确决策转化为巨额伤害、将错误决策转化为重生画面的职业。弄清楚你正在助长这个等式的哪一半，是提升最快的方法。

### 弓箭手的优势所在

| 优势 | 如何利用 |
|---|---|
| 高远程爆发 | 每场战斗都从最大距离起手，在敌人朝你移动前开火 |
| 低成本、低风险刷取 | 刷那些用其他职业近战绝对无法安全处理的精英 |
| 强大的暴击与攻速收益 | 武器成型后优先选择乘法类属性 |
| 出色的单体专注 | 融化那些惩罚低伤害的 Boss 和具名精英 |
| 对团队友好的输出覆盖率 | 待在坦克身后持续开火，而不是在近战范围里闪避 |

### 弓箭手的劣势所在

| 弱点 | 实用应对 |
|---|---|
| 有效生命值低 | 把每次受到的伤害都视为值得复盘的失误 |
| 被突进技能惩罚 | 把冲刺留给敌人的冲锋，而不是用来赶路 |
| 前期依赖装备 | 优先升级武器，再考虑任何防御部位 |
| 前期升级较慢 | 预期开局艰难，技能补全后会逐渐顺畅 |
| 在狭小场地表现差 | 拉怪前先站位到开阔地附近 |

从玩家经验来看，大多数弓箭手的死亡都可追溯到一个习惯：在重新调整站位前多射了一箭。这个职业会奖励那些把伤害窗口最后半秒视为神圣不可侵犯的玩家。

## 弓箭手职业的属性优先级与配装流派

没有唯一正确的弓箭手配装。重要的是你的属性、技能和装备都指向同一个方向。将一半投入暴击、一半投入持续伤害的配装，通常不如专注其中任一种的配装。

### 四种常见弓箭手配装

| 配装 | 核心属性 | 玩法 | 最适合 | 难度 |
|---|---|---|---|---|
| 精准 / 暴击 | 暴击率、暴击伤害、命中 | 缓慢、沉重、刻意的一击 | Boss 战、单体目标 | 中等 |
| 箭雨 / 攻速 | 攻击速度、命中效果、范围伤害 | 持续施压、清屏 | 刷取、杂兵群 | 低 |
| 游击 / 机动 | 移动速度、冷却缩减、闪避 | 打了就跑、不断重新站位 | PvP、单刷精英 | 高 |
| 元素 / 持续伤害 | 元素伤害、异常状态几率、穿透 | 叠加减益并等待其持续生效 | 团队玩法、高坦度目标 | 中等 |

### 建议属性优先级顺序

| 优先级 | 属性类别 | 为什么排在这里 |
|---|---|---|
| 1 | 武器基础伤害 | 其他一切都以它为乘法基础 |
| 2 | 暴击率与暴击伤害 | 最大且可靠的伤害乘区 |
| 3 | 攻击速度 | 同时提升伤害与命中效果的触发频率 |
| 4 | 移动速度 | 直接转化为生存与输出覆盖率 |
| 5 | 冷却缩减 | 每场战斗能使用更多冲刺与功能技能 |
| 6 | 防御属性 | 有用，但永远无法替代站位 |

社区反馈一致指出，新手弓箭手过早地在防御属性上投入过多。一个稍微更肉、却什么都杀不掉的弓箭手仍然会死——只是死得更慢。

## 技能、循环与站位技巧

技能名称和数值会随补丁变化，因此请关注一场战斗的形态，而不是背下来的固定顺序。几乎每个弓箭手技能组都遵循相同的四阶段节奏。

### 弓箭手战斗的四个阶段

| 阶段 | 目标 | 你要做什么 |
|---|---|---|
| 起手 | 在敌人反应前最大化爆发 | 从最大距离射出你最重的远程技能 |
| 持续 | 保持伤害输出而不冒进 | 一边侧移一边交替使用普通攻击和低耗技能 |
| 脱离 | 重置距离 | 一旦有东西逼近，立刻冲刺或翻滚拉开 |
| 重置 | 按你的条件重新接战 | 重新施加减速或定身，然后重新开始起手 |

### 真正重要的站位规则

- **绝不要为了读完施法而站定不动**，如果有近战敌人距你只有一次冲刺的距离。
- **沿着墙壁和走廊作战**，这样你永远只会面对一个方向的敌人。
- **用射程拉怪，而不是用脚。** 走进怪堆会剥夺你最大的优势。
- **追踪敌人的突进技能**，就像坦克追踪冷却一样——它们决定了你的伤害窗口。
- **始终保留一个未使用的逃生手段**；浪费掉的冲刺等于死刑。

当你把每场战斗都视为一场关于距离的谈判时，Lootborne 弓箭手职业就能如鱼得水。赢下这场谈判，伤害自然会解决一切。

## 弓箭手职业的装备、掉落与成长

由于 Lootborne 围绕掉落展开，你的配装在一定程度上是与随机性的谈判。你仍然可以通过升级优先级和掉落过滤来大幅引导它。

### 装备部位优先级

| 部位 | 优先级 | 理由 |
|---|---|---|
| 武器 | 最高 | 基础伤害会缩放几乎所有弓箭手技能 |
| 副手 / 箭袋 | 高 | 通常带有暴击、攻速或投射物词缀 |
| 手套 | 高 | 常常是攻击词缀的主要来源 |
| 靴子 | 中高 | 对远程配装而言，移动速度就是防御属性 |
| 胸甲 | 中 | 选它是为了生命和抗性，而不是伤害 |
| 头盔 | 中 | 功能性与冷却缩减通常在这里 |
| 戒指 / 项链 | 视情况而定 | 最适合用来补足你配装所缺的部分 |

### 成长清单

1. 在更高难度追求伤害之前，**先把抗性堆满**。
2. 每次进入新阶段时，**优先升级武器**——它是最大的单次战力跃升。
3. **设置掉落过滤器**，高亮你的武器类型、暴击词缀和移动速度。
4. **保留一把备用武器**，用于元素或单体切换。
5. **存下制作材料**，而不是把它们赌在边际提升上。

平衡改动可能会迅速改变这些优先级，因此在重大更新后，值得在诸如 [Steam 商店页面](https://store.steampowered.com/) 这样的商店平台上查看官方补丁说明。让配装适应重做，远比和它对抗便宜得多。

## 团队玩法、PvP 与常见错误

Lootborne 弓箭手职业在队伍中会改变性质。单人时，你要为自己的距离负责。在团队中，前排能为你买到你自己买不到的东西：不间断的输出覆盖率。

### 弓箭手在不同内容中的职责

| 内容 | 你的职责 | 需要小心 |
|---|---|---|
| 单人刷取 | 控制拉怪，控制节奏 | 被两个方向包围 |
| 团队 PvE | 从最大距离集火威胁最高的目标 | 站在坦克的近战堆里 |
| Boss 战 | 在移动阶段保持输出覆盖率 | 慌乱冲刺进有预警的攻击中 |
| PvP | 惩罚过度深入的玩家，立刻脱离 | 专门为你留的突进技能 |

### 常见错误与修正

| 错误 | 修正 |
|---|---|
| 纯玻璃大炮配装 | 增加一到两层防御，不要再多了 |
| 追残血追进近战范围 | 让低血量敌人自己过来 |
| 忽视移动速度 | 把它当作核心攻击属性 |
| 把冲刺浪费在赶路上 | 只在逃跑或躲避预警时使用 |
| 盲目照抄配装 | 让配装匹配你实际拥有的掉落 |

还有一个习惯能区分优秀弓箭手和顶尖弓箭手：每次死亡后，问自己战斗的哪个阶段崩了。通常答案是脱离阶段，而不是伤害阶段。

## 常见问题

### Lootborne 弓箭手职业适合新手吗？

如果你喜欢远程战斗，这是一个合理的首发选择，但要预期会有学习曲线。这个职业对糟糕站位的容忍度远低于近战猛男。新手应从箭雨或攻速配装起步，因为它更宽容，并能快速清理前期内容。等你熟悉风筝后，可以转向精准或游击配置。

### Lootborne 弓箭手职业应该优先堆哪些属性？

从武器基础伤害开始，然后是暴击率和暴击伤害，再是攻击速度。接下来是移动速度，因为它对远程角色而言既是进攻也是防御。抗性在你进入更难内容后才重要，但前期大量投资纯防御往往会拖慢进度，却不会显著改善生存能力。

### 弓箭手职业在团队玩法和 PvP 中可用吗？

可以，两者都可用。在团队 PvE 中，只要前排能把敌人固定住，弓箭手就能提供游戏中最高的一档持续单体伤害。在 PvP 中，这个职业扮演惩罚型游击手——你通过诱骗突进、脱离，再按自己的条件重新接战来取胜。社区反馈表明，机动性重的游击变体在竞技玩法中表现最好。

### 玩弓箭手时怎样才能不再频繁死亡？

慢下来。大多数弓箭手的死亡都来自多射了一箭，而不是重新站位。始终保留一个未使用的逃生手段，在开阔地或沿墙作战，并从最大距离拉怪。如果你仍然挣扎，就给装备增加一层防御，把其余投入重新放回伤害和移动速度。
